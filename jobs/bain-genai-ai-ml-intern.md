# AI / ML Engineering Intern - GenAI
Bain (client-facing, engagement teams; references Bain's Responsible AI standards)

## Responsibilities
- Design and build GenAI applications (copilots, workflow automation, decision
  support) on modern LLM stacks
- AI pipelines: RAG, fine-tuning and parameter-efficient tuning, embedding
  generation and optimization, hybrid retrieval (vector, graph, keyword)
- Tool use, function calling, orchestration across AI workflows
- Agent capabilities: context engineering, memory and state management,
  orchestration, tool integration
- Model experimentation, evaluation design, production deployment
- Clean testable code; APIs and services through the full SDLC: build, test,
  deploy, monitor, iterate
- Evaluation and observability for GenAI: regression test suites, automated
  scoring, prompt or policy iteration loops
- Responsible AI: guardrails, fallbacks, human-in-the-loop (HITL) workflows
- Evaluation harnesses and reusable components across client contexts
- ML end to end: data prep, feature engineering, model selection, training,
  validation, testing, performance analysis; classical ML and deep learning
- Transformer fundamentals and LLM concepts
- Collaborate with product, engineering and data science
- Communicate to technical and non-technical audiences; demos, documentation
- Support client discussions as part of engagement teams

## What they are looking for
- 0-2+ years AI/ML engineering, or equivalent through internships, research,
  academic projects, or open-source
- Pursuing or recently completed BS/MS/PhD in CS, ML, AI, Data Science,
  Engineering or related quantitative field
- Strong academic performance, or demonstrated excellence through research,
  projects, internships, competitions, or open source
- Proficiency in Python and some experience building APIs (REST/gRPC)
- Experience building complex, multi-stack generative AI programs from
  conception through production
- Exposure to retrieval and search systems (vector search, hybrid retrieval,
  reranking); structured and unstructured data stores
- Exposure to agentic patterns (context management, tool integration,
  orchestration, memory/state handling); hands-on preferred
- Strong engineering practices: testing, code review, version control, CI/CD,
  performance profiling
- Excellent interpersonal and communication skills; client-facing

Successful interns may be considered for full-time offers.
